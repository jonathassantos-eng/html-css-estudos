## 📌 Sobre o Repositório

Este repositório reúne a progressão prática de aprendizado em **desenvolvimento web frontend com HTML5 e CSS3**. Os exercícios estão organizados de forma modular, cobrindo desde a fundação da marcação estrutural até tabelas avançadas, formulários, estilização em cascata e integração de fontes externas.
