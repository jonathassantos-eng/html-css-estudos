## 📌 Sobre o Repositório

Este repositório reúne a progressão prática de aprendizado em **desenvolvimento web frontend com HTML5**. Os exercícios estão organizados de forma modular, cobrindo desde a fundação da marcação estrutural até a construção de formulários interativos com validações nativas.
